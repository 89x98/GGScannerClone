`equipped_path_badges.png` contains five sanitized, neutral glyph masks from
the inventory Equipped strip (34 × 34 pixels per tile at 1920 × 1080).
Left to right: Hunt, Harmony, Preservation, Remembrance, Elation. No portraits,
names, account text, or item identity is included. Labels come from the visible
Path symbols, independent of the equipped item's class.

The inventory uses decorated badges rather than the plain Character-header
symbols. The detector searches the strip for a close, unique glyph match and
rejects unsupported badges. It is used only to distinguish Path variants of
the character independently identified through the read-only Equipped link.
